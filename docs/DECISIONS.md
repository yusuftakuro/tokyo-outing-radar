# 開発判断（2026-10-12時点）

## 何を作るか
東京近郊のリアルな催しを、散歩や外出の理由として提案するWebサイト。既存サイトのような大量一覧や、「AIらしい」誇張した演出は避ける。ユーザーが開いて短時間で街へ出る気になれることを重視。

## 初期UI
- B案「東京で何か起きている型」：少数の実イベントをトップで見せる
- 「行き先をひとつ出す」で街／代表駅を1件表示
- 気に入らなければ「別の街を見る」、気になれば詳細・公式・経路へ
- 決定／到着報告、ゲーム性、スタンプ、ログインを作らない
- カテゴリ別イベント羅列検索、不要な写真や装飾、過剰なキャッチコピーは作らない

## 推薦とデータ
- 「今日行く理由」が強い限定催事を基本的に優先
- イベント優先だが、候補が薄い場合は常設の街歩きを出す。限定催事だと偽らない
- 予約必須は除外。予約必要なサブ企画を自由観覧と混同しない
- 日付・時刻・予算で絞る。出発駅からの概略的な距離で順位調整するが、電車時間は未対応
- エリアは内部ID・表示用代表駅。近隣駅を別エリアとして連発しない
- 常設の街候補の30日クールダウンを端末内で処理する（新候補が尽きた場合は例外）
- 日付・料金・予約要否・情報源URL・検証日を保管する
- 交通費は予算に含めない

## 制約と優先順位
- 本版はデータを人手で公式確認・登録した静的アプリ。自動収集・天気補正・乗換時間は未対応
- 情報源の正確性と開催日時の鮮度をUIの見栄えより優先
- 本番表示の更新を全自動で始める前に、収集先の利用条件と取得方法を確認し、検査・差分ログ・承認経路を設ける
- 将来公開サービスも視野にするが、初期は自分の外出に役立つかで評価する
